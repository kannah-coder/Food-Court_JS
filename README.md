# Food-Court_JS
# 🍴 Food Court — Interactive Menu & Cart System

A **modern, responsive food ordering web application** built with **HTML, CSS, and Vanilla JavaScript**.
This project showcases **real-world e-commerce features** like **search, filtering, sorting, cart management, and live price updates**, wrapped in a clean, professional UI.

Perfect for **resume & portfolio display** — demonstrates **frontend mastery** and **problem-solving skills** without relying on frameworks.

---

## ✨ Features

* 🔍 **Smart Search** — search by dish name or restaurant
* 🥗 **Category Filters** — filter menu items by Veg, Non-Veg, Drinks, or Sides
* ↕️ **Dynamic Sorting** — sort by price (low → high, high → low) or rating
* 🛒 **Interactive Cart**

  * Add items with quantity tracking
  * Remove items instantly
  * Auto-updating total price & item count
* ⭐ **Ratings Display** — products show user ratings (★ 1–5)
* 📱 **Responsive Design** — optimized for both desktop and mobile
* 🎨 **Modern UI/UX** — glassmorphism, gradients, smooth hover effects

---

## 🖥️ Tech Stack

* **HTML5** — semantic structure
* **CSS3** — responsive grid, custom variables, modern effects
* **Vanilla JavaScript (ES6)** — DOM manipulation, event handling, cart logic

## 🧑‍💻 How It Works

1. Browse products in the **menu grid**
2. Use **filters** or **sort options** to narrow results
3. Add items to cart with the **“Add” button**
4. View cart in a sticky sidebar or full-page overlay (mobile)
5. Remove items or track total cost live
